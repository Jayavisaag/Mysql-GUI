# 🗄️ MySQL Admin Pro

A lightweight, feature-rich Graphical User Interface (GUI) for managing MySQL databases, built entirely with Python and Tkinter.

## ✨ Features
* **Database Management:** Create, drop, and switch between databases effortlessly.
* **Table Management:** Create new tables, manage columns (add, modify, delete, reorder), and rename or drop tables.
* **Record Operations (CRUD):** Insert, update, view, and delete records with an intuitive form and data grid.
* **SQL Terminal:** Execute custom SQL queries directly within the app and view the results.
* **User Management:** Create new MySQL users, grant/revoke all privileges, and remove users.
* **Data Export:** Export table data directly to CSV format.
* **Console Log:** Real-time tracking of operations, successes, and errors.

## 🛠️ Prerequisites
Before running this application, ensure you have the following installed:
1. Python 3.x
2. A running MySQL Server (e.g., via XAMPP, WAMP, or standalone MySQL installation)

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jayavisaag/Mysql-GUI.git
   cd Mysql-GUI
   ```

2. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python pythonguiupdateduuuu.py
   ```

## 🔐 Login
Upon launching, connect to your database using your MySQL credentials (the default host is usually `localhost`).
